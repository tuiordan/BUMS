Software Engineering Assignment 2

User Stories

The following user stories describe the main actions and goals identified from RepRight's personas and usage scenarios.

Persona 1

Jake Thompson

Beginner Lifter

Scenario 1: Analyzing Squat Technique

View Scenario
  1. As a beginner lifter, I want to upload a video of my squat so that I can receive feedback on my technique.
  2. As a beginner lifter, I want to label my uploaded video as a squat so that RepRight analyzes the correct movement.
  3. As a beginner lifter, I want to see feedback about squat depth so that I know whether I am lowering far enough.
  4. As a beginner lifter, I want to see possible knee and back alignment issues so that I know what to correct.
  5. As a beginner lifter, I want to save my squat analysis so that I can review it before my next set.

Scenario 2: Learning a New Exercise

View Scenario
  1. As a beginner lifter, I want to browse exercises by muscle group so that I can find movements suitable for my workout.
  2. As a beginner lifter, I want to watch a demonstration of an exercise so that I can see the correct starting position.
  3. As a beginner lifter, I want step-by-step exercise instructions so that I can practice a movement safely.
  4. As a beginner lifter, I want to review common technique mistakes so that I know what to watch for.
  5. As a beginner lifter, I want to save exercises to a favorites list so that I can find them quickly at the gym.

Scenario 3: Tracking Technique Improvement

View Scenario
  1. As a beginner lifter, I want my previous analyses saved by exercise so that I can find older results.
  2. As a beginner lifter, I want to compare two squat videos so that I can see how my technique has changed.
  3. As a beginner lifter, I want to view a history of form scores so that I can recognize improvement over time.
  4. As a beginner lifter, I want to see which form issues keep recurring so that I can focus on those corrections.
  5. As a beginner lifter, I want to add notes to an analysis so that I can remember what I practiced.

Persona 2

Sarah Mitchell

Experienced Lifter

Scenario 1: Improving Deadlift Technique

View Scenario
  1. As an experienced lifter, I want to upload a deadlift video so that I can assess my lifting technique.
  2. As an experienced lifter, I want to view feedback on my back and hip positioning so that I can identify potential form faults.
  3. As an experienced lifter, I want to replay marked moments in my video so that I can see exactly when an issue occurs.
  4. As an experienced lifter, I want specific correction suggestions so that I can adjust my next set.
  5. As an experienced lifter, I want to record the weight lifted with each video so that I can interpret technique feedback in context.

Scenario 2: Comparing Workout Recordings

View Scenario
  1. As an experienced lifter, I want to select two recordings of the same exercise so that I can compare them.
  2. As an experienced lifter, I want to watch recordings side by side so that I can spot differences in movement.
  3. As an experienced lifter, I want to compare form feedback from two sessions so that I can evaluate progress.
  4. As an experienced lifter, I want to filter saved videos by exercise so that I can locate relevant comparisons.
  5. As an experienced lifter, I want to see recording dates and weights so that I can understand the conditions of each attempt.

Scenario 3: Customizing Form Feedback

View Scenario
  1. As an experienced lifter, I want to choose concise or detailed feedback so that the analysis matches my needs.
  2. As an experienced lifter, I want to prioritize specific movement checkpoints so that I can focus on one technical goal.
  3. As an experienced lifter, I want to control video playback speed so that I can inspect complex movements.
  4. As an experienced lifter, I want explanations of the metrics used so that I can understand the feedback.
  5. As an experienced lifter, I want my feedback preferences saved so that I do not have to reconfigure them each session.

Persona 3

Marcus Davis

College Athlete

Scenario 1: Reviewing a Strength Session

View Scenario
  1. As a college athlete, I want to upload videos from my strength workout so that I can review my technique afterward.
  2. As a college athlete, I want to label videos by exercise so that my training sessions stay organized.
  3. As a college athlete, I want to receive feedback on movement alignment so that I can identify technique issues.
  4. As a college athlete, I want to review feedback between sets so that I can adjust my next attempt.
  5. As a college athlete, I want to store each session date so that I can track when my recordings were made.

Scenario 2: Checking Technique Consistency

View Scenario
  1. As a college athlete, I want to compare form results across sessions so that I can assess consistency.
  2. As a college athlete, I want to see trends for the same exercise so that I can identify repeatable technique changes.
  3. As a college athlete, I want to flag an unusually poor set so that I can revisit the recording.
  4. As a college athlete, I want to add session notes so that I can connect technique changes with fatigue or workload.
  5. As a college athlete, I want to review recurring form warnings so that I can plan what to practice.

Scenario 3: Sharing Results with a Coach

View Scenario
  1. As a college athlete, I want to share a saved exercise analysis with my coach so that we can review my technique together.
  2. As a college athlete, I want to choose which video and feedback are shared so that I control my workout information.
  3. As a college athlete, I want to generate a restricted sharing link so that only intended people can view my analysis.
  4. As a college athlete, I want my coach to see the form observations attached to my recording so that we can discuss specific moments.
  5. As a college athlete, I want to revoke shared access so that I remain in control of my workout data.

Persona 4

Emily Carter

Personal Trainer

Scenario 1: Reviewing a Client Exercise Video

View Scenario
  1. As a personal trainer, I want to open a client's submitted exercise video so that I can review their technique.
  2. As a personal trainer, I want to see AI-generated observations linked to video timestamps so that I can quickly locate important moments.
  3. As a personal trainer, I want to watch the full exercise video myself so that I can form my own professional assessment.
  4. As a personal trainer, I want AI observations to remain separate from trainer feedback so that clients can distinguish between them.
  5. As a personal trainer, I want reviewed videos saved to a client's history so that I can revisit them during future sessions.

Scenario 2: Giving Personalized Client Feedback

View Scenario
  1. As a personal trainer, I want to pause a client's exercise video at a specific moment so that I can comment on that movement.
  2. As a personal trainer, I want to attach my coaching notes to video timestamps so that clients know exactly what my feedback refers to.
  3. As a personal trainer, I want to add positive feedback as well as corrections so that clients know what they are doing well.
  4. As a personal trainer, I want my comments to be visually separate from AI observations so that clients can distinguish between the two.
  5. As a personal trainer, I want to send an annotated review to a client so that they can revisit my coaching feedback between sessions.

Scenario 3: Monitoring Client Progress

View Scenario
  1. As a personal trainer, I want to view a client's exercise history so that I can review progress across multiple sessions.
  2. As a personal trainer, I want to filter client recordings by exercise so that I can quickly find comparable videos.
  3. As a personal trainer, I want to compare older and recent client videos so that I can evaluate changes in technique.
  4. As a personal trainer, I want to review previous trainer notes and form observations so that I can understand the client's progress in context.
  5. As a personal trainer, I want to save a progress summary and new practice goal so that the client has a clear focus for future sessions.
